# ADR-0007: the title

**Date:** 2026-09-24

## Decision

English: *One Page at a Time: Delivering Software and Projects with Coding Agents*.
Portuguese: *Uma Página de Cada Vez: entregando software e projetos com agentes de IA*.

## Consequences

The title names the book's central rule, one delivery per page, and admits projects that are not software.
