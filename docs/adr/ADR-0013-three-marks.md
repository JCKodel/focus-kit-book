# ADR-0013: three marks only

**Date:** 2026-09-24

## Context

Case A added a fourth mark, `[?]`, for lines waiting on a person's answer.
Here, the only outside answer is the author's approval of anonymized text.

## Decision

The queue uses the kit's three marks: `[ ]`, `[>]`, `[x]`.
The author's approval is a line of the chapter page's Done when.

## Consequences

Chapter 21 teaches `[?]` from Case A, as a customization this project did not need.
