# ADR-0006: "focus-kit" names the method; FOCUS names only the architecture

**Date:** 2026-09-24

## Context

The kit was born from the FOCUS architecture but offers it as optional.
The method works on projects where no architecture applies, such as this book.
A third name for the process would be one more thing for the reader to learn.

## Decision

The method and its tool share the name focus-kit.
FOCUS remains the name of the optional architecture only.

## Consequences

Part II teaches focus-kit; Part III teaches FOCUS and says plainly that it is optional.
