# 2026-06-16 — check-in with Odile: overdue members & borrowing

Tue 16 June, 14:00–14:50, Saltgate back office + Rafe dialled in
Present: Odile Fenwick, Wren Halloway (second half), Juno Achterberg, Tamsin Oduya, Rafe Lindqvist, Marek Szolt, Bex Amadi
Notes: TO

## Context

On 8 April we wrote down that members with overdue loans can keep borrowing until they actually get suspended (i.e. until something is more than 14 days late). That was based on how Wren described the desk in practice — "we don't turn people away for being a few days late". It's what the model has done since April.

Odile has been watching the test list and raised it last week on the chat: Odile doesn't like it, and wants it reversed before anyone outside the team starts relying on the current behaviour. Today was to settle it.

## Discussion

**Odile's position:** if you've got a book that's late, you don't get another one until it's back. Simple to explain at the desk, and it's what the library *says* the rule is on the poster by the door, even if the desk has been soft about it. "Being kind for two weeks and then suspending someone is worse than being clear on day one."

**Wren** (joined ~14:25): agreed, somewhat to everyone's surprise. The April description was what the desk does, not what it thinks it should do. With the new loan period being longer, people have less excuse. Wren's one worry: people who are a day late and come in to return *and* borrow in the same visit. → That's fine, they return first, then nothing's overdue, then they can borrow. Order at the desk matters, not the rule.

**Rafe** asked whether this makes suspension pointless. Tamsin/Juno: no — suspension still matters because it also blocks renewals, sticks until a librarian lifts it, and is a record that something went badly. "Overdue blocks borrowing" is the soft stop; suspension is the hard one.

**Marek** checked: "overdue" here means exactly the same thing as everywhere else in the model — same `isOverdue`, no separate grace period. Agreed, no grace period. One definition.

**Bex** asked about renewals for a member who has one overdue loan and another loan that's fine. Decision: renewing the *other* loan is still allowed (only the overdue one itself can't be renewed). Odile: "renewing isn't taking more books home". OK — no change there.

Juno asked if anyone wanted to keep the April behaviour as an option/flag. Nobody did. Tamsin: a flag means two sets of tests and two sets of explanations at the desk, for a rule the library doesn't actually want.

**Odile**, on wording: the librarian should be able to say *why* in one sentence. "You've got a book that's overdue — bring it back and you can take this one." The error code maps straight onto that.

## Decision

**A member with ANY overdue loan cannot check out more.** This replaces the 8 April note (members could keep borrowing until suspended). Returns are always allowed; renewals of non-overdue loans unchanged; suspension rule unchanged.

## Code change (done same evening, RL, reviewed TO)

- New error code `member-has-overdue-loans` in `LoanError`.
- `checkOut` checks it right after the suspension check and before the loan limit:
  1. `member-suspended`
  2. `member-has-overdue-loans`
  3. `loan-limit-reached`
  4. copy checks
- Order matters for which message the librarian sees: suspended trumps overdue, overdue trumps "too many books".
- Test: `refuses a member who has an overdue loan, even before suspension` (loan 2 days late, nowhere near the threshold).
- Glossary "Checkout" entry updated. Marked the 8 April note with a pointer to this one.
