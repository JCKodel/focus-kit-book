# Rubric

Each answer is scored 1 (poor) to 5 (excellent) on each criterion of its arm. An answer is the files the agent left in the run folder plus the agent's last text block of that state, as `answer.md` beside them.

## limit

1. Does what was asked.
2. Looks like a small app.
3. Works on the phone.

Counted apart: the card shows three tabs that switch in the Adaptive Cards Designer with the Microsoft Teams host, yes or no.

## audience

1. A board member can decide in 10 minutes.
2. Nothing the decision needs is missing.
3. Every figure matches the report.

## cost

1. An agent finds what it needs without reading everything.
2. The setup stays right as the notes grow.
3. It is easy for a person to keep up to date.

## Every pair

Which would you send, X or Y?
