# m4.2-review

**Objective.** After this delivery the author knows whether M4.2's fixes left the book or the clinic wrong, from a review that reads only what M4.2's lines changed, in both editions, and every finding it judges real, blocking or not, waits as a line at the start of M5; no M4.3 opens. The review is recorded so that chapter 23 can tell it.

**Behaviour.**

* A fresh session reads only what M4.2's lines changed: the book's diff, both editions, and the clinic's diff. It does not reread the book. It may open a changed chapter only to see the section a hunk sits in, and nothing else. It edits nothing.
* It checks M4.2's paragraph clause by clause. Each clause gets the changed chapter and section that answers it, or the clinic commit that does. A clause no change answers is a finding.
* It reports a finding only on a changed line or a sentence around it in the same section, and marks each one blocking or not blocking, with its reason. Blocking, as docs/05 §8 says: a sentence the book shows to be false, or a step the reader cannot follow. For the clinic's code: the code does not do what M4.2's clause says, or a test in the range fails.
* The /apply session checks each finding against the text or the code and gives its assessment. The author decides each one: blocking, not blocking (real, but not blocking) or rejected, with a one-sentence reason. Nothing is fixed.
* Every blocking and every not-blocking finding becomes a `[ ]` line at the start of M5, before `git-essentials`, written by the review's session. A rejected finding adds no line. No M4.3 is created.
* The whole run is recorded, so chapter 23 can tell it and quote it.

**Contract.**

* Model `claude-opus-5-5`, the model of m3-review, m4-review and m4.1-review, on both turns.

**Out of scope.**

* Fixing any finding: each waits as a line at the start of M5.
* Rereading the book, or any line M4.2 did not change: §8 says a last round reads only what its lines changed.
* A separate `m4.2-code-review` with `/code-review high`: the queue has none, and the two clinic commits (34 lines in `src/` and docs/01) are read by this session against M4.2's clause.
* Opening M4.3: §8 allows one round of fixes, and M4.2 counts as M4's last.
* Changing §8's recipe for a last round: this is its first occurrence.
* Telling this review in the book: that belongs to chapter 23.
* `make book`: no chapter changes.
