**How it works now**
- `hoursReported` is still the one event, but it no longer waits by default. It returns the state change directly for `"saving"`, `"saved"`, `"failed"` and `"NotSignedIn"`. Only `"ProfessionalNotFound"`, which has to reload the list, returns a promise.
- `useProfessionals` applies a direct answer at once and waits only for the promise.
- Each test now also fails if a report that needs no reload returns a promise. The `ProfessionalNotFound` test checks that its answer is a promise.

**Two ways this differs from the option as my page first wrote it** (both recorded on the page):
1. The event returns a state change, not a finished state, because the hook can't read the current state at that moment.
2. `"NotSignedIn"` is immediate too, because it needs no repository and you said only those may wait.
