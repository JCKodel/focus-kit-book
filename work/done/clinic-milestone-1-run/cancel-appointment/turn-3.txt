**What a client can now do**
- **From "Your appointments":** each appointment still more than 24 hours away has a "Cancel" button. It asks for confirmation, and then the time is free again for everyone. If the appointment was already cancelled elsewhere, the phone forgets it and says so. If the server says it's too late, the line says why and keeps the appointment.
- **With "Cancel with a booking code":** the client types the phone number and code. Lower case, spaces around the code and spaces in the phone number all work. A wrong code, blank fields and "too late" each show their message above the form.
- **Nothing is deleted:** a cancelled appointment keeps its row. If two cancellations of the same appointment race, exactly one succeeds and the other gets "not found".

**Where I went beyond or away from the page** (each one is recorded in the page)
- **Shared code on its second use.** None of these was named on the page, so I'm stating which use came first:
