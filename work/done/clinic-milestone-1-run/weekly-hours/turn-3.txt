**Changes the page didn't name** (each one is recorded in `work/done/weekly-hours.md`):
- **Shared transaction helper.** Saving hours is the second place that writes several rows together (the first is `saveClinicAndOwner`), so both now use a new `transaction` helper in `database.server.ts`.
- **Shared id check.** The check that a route's `:id` is a positive whole number moved from the professionals routes to `src/lib/id.ts`, since the hours routes need it too.
- **Editor props.** `WeeklyHoursView` also takes `busy` and `section`. That is how it reports "no longer exists" and "session ended" up to the professionals section, which the page asked for.
- **Rule checked before sending.** The screen checks the hours rule before it saves and sends nothing if a period is refused. So the client treats a `400` from the server as "cannot be reached".
- **Browser validation off.** The form has `noValidate`; otherwise the browser would block 09:03 with its own bubble instead of the page's message.
- **Message placement.** A refusal message appears under its period's line, not to its right: on a phone that line already fills the width.
