# agent-never-unsure

Draft, from the author's reading of the book on 2026-10-18. /propose finds the best place (chapter 1, How an agent sees your project, is the first candidate).

* An agent never says "I don't know". It says what it does not know with the same assertiveness as what it knows.
* It may invent; it may use something in the model that has nothing to do with the project; or, rarely, it warns subtly that it does not know but has ideas to gather evidence for a hypothesis.
* A hypothesis is not always true.
* Human judgment is still the IT professional's main asset.
