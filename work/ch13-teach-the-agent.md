# ch13-teach-the-agent

Draft, from the author's reading of the book on 2026-10-18.

* In "Review the staged change", talk to the agent about problems: if you prefer the code a certain way, tell the agent and explain what you want instead of fixing it yourself.
* Many agents keep a memory that is updated by your corrections; some can change the kit's files, write new ADRs, and so on.
* Early in a project it is normal for agents to do things that do not suit the team's taste or needs; teaching the agent is the most efficient way for it to learn and make fewer mistakes later.
* Treat the agent as a member of the team.
